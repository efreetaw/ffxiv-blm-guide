# 第二题：基准循环只打完1—13个GCD时，ΔP是多少？

目标在第n个GCD完成后死亡，n取1—13，每发技能必定命中。**前12种情况的累计ΔP均为负，完整打完13发时归零；最低点在第4发，约为−570.46。**

## 1. 循环与算法

采用[7.2注释版的单体基准循环](../../blm/nga-43757414/7.2黑魔进阶攻略-原文注释版.html#section-9)，按固定顺序施放：

```text
冰3 → 冰4 → 冰悖论 → AF1火3 → 火4×6 → 火悖论 → 耀星 → 绝望
```

即刻与星灵移位是能力技，占用0个GCD。上面13发总威力为6846，按整数GCD计时。

```text
Q = 6846/13 = 526.615384615…
S_n = 前n发技能的累计威力
ΔP_n = S_n − n×Q
```

ΔP表示这n发相对基准平均线的累计盈亏：正数高于平均线，负数低于平均线。计算保留Q的完整精度，表格最后舍入到两位小数。

## 3. 样例：冰悖论起手+1G，中途U3d+3G

**前段多打4个GCD，挤掉原本末尾的4发技能，最终相对原轴提升580威力。**

固定目标死亡时点：原轴恰好打完最后一轮基准循环的第4发。两边起手都用AF1火3（406威力），改轴在起手星灵移位前多打一发冰悖论，中途再插入U3d。冰悖论、火苗及回蓝满足施放需要，X、Y代表两边技能与伤害相同的其余流程。

```text
原轴：星灵移位 → AF1火3 → X → Y → 冰3 → 冰4 → 冰悖论 → AF1火3 → 目标死亡
改轴：冰悖论 → 星灵移位 → AF1火3 → X → U3d → Y → 目标死亡
```

星灵移位占0个GCD，起手增加的1G来自冰悖论。U3d按注释版展开为`冰悖论 → AF1火3 → 绝望`，共3G、1576威力。两处合计增加4G，正好占用原轴末尾4G的时间，因此两条轴在死亡前打出的总GCD数相同。

| 前段改动 | 增加GCD | 增加威力 | 扣除GCD成本后的收益 |
| --- | ---: | ---: | --- |
| 起手增加冰悖论 | +1 | 540 | 540 − Q ≈ +13.3846 |
| 中途插入U3d | +3 | 540 + 406 + 630 = 1576 | 1576 − 3Q ≈ −3.8462 |
| 合计 | +4 | 2116 | p₁ = 2116 − 4Q ≈ +9.5385 |

被挤掉的末尾4发总威力为`290 + 300 + 540 + 406 = 1536`，其累计ΔP为`1536 − 4Q ≈ −570.4615`。所以最终提升为：

```text
提升 = 前段增加的收益 − 被挤掉的末尾ΔP
     = p₁ − (1536 − 4Q)
     = (2116 − 4Q) − (1536 − 4Q)
     = 2116 − 1536
     = 580威力
```

也就是`p₁ + 570.4615… = 580`。若原轴前置流程的累计ΔP记为P前，原轴最终约为`P前 − 570.46`，改轴最终约为`P前 + 9.54`；580是两条轴之间的提升。

## 4. 样例：8—9核心G的B4核耀斩杀特化

采用[第二节HTML的收益对比方案](../../docs/不定gcd下的截断特化/index.html#2-6)。**8G与9G的B4核耀方案都比同核心G数的截断基准多502威力。**双方相同的雷与异言抵消，按核心G计数。

斩杀方案承接前一火段，星灵进入冰阶段后用B4取得3根冰针，进火≥3200MP；预存火苗，火3前移位到AF1，火苗火3按406威力计算。完整前置见[斩杀特化研究](execute-rotations.md)。

```text
基准前8G：冰3 → 冰4 → 冰悖论 → AF1火3 → 火4×4
斩杀8G：  冰4 → 冰悖论 → AF1火3 → 火4×3 → 核爆 → 耀星

基准前9G：冰3 → 冰4 → 冰悖论 → AF1火3 → 火4×5
斩杀9G：  冰4 → 冰悖论 → AF1火3 → 火4×3 → 核爆 → 耀星 → 冰悖论
```

3发火4消耗2400MP与3根冰针，给核爆留至少800MP；火4与核爆合计取得6层星极魂，再打耀星。9G在收尾移位后补末尾U，移位回转由实际填充安排满足。

| 打法 | 核心威力 S | ΔP＝S−N×Q | 相对同核心G数基准的提升 |
| --- | ---: | ---: | ---: |
| 基准循环前8G | 3696 | −516.92 | — |
| B4核耀8G | 4198 | −14.92 | +502 |
| 基准循环前9G | 4236 | −503.54 | — |
| B4核耀9G | 4738 | −1.54 | +502 |

相同核心G数互相比较时，N×Q抵消。8G抵消共同技能后：

```text
基准：冰3 + 火4 = 290 + 540 = 830
斩杀：核爆 + 耀星 = 432 + 900 = 1332
提升：1332 − 830 = 502威力
```

9G比8G多出的技能分别是基准火4与斩杀末U，两者均为540威力，因此提升仍为502。

## 5. 样例：魔泉启动常规火段，+570.46、−4G

**以完整13G／6846威力的基准循环为参照，魔泉启动的常规火段为9G／5310威力，因此ΔGCD＝−4，ΔP≈＋570.46。**

魔泉可用时，在火状态下施放，恢复满蓝并补齐AF3、3根冰针和悖论。魔泉本身占0个GCD，随后打出常规火段：

```text
魔泉 → 火4×6 → 火悖论 → 耀星 → 绝望
```

按`Q＝6846/13`计算：

```text
G = 6＋1＋1＋1 = 9
S = 6×540＋540＋900＋630 = 5310

ΔGCD = 9−13 = −4
ΔP   = (5310−6846) − Q×(9−13)
     = −1536＋4Q
     ≈ ＋570.46
```

省掉的是基准开头的`冰3 → 冰4 → 冰悖论 → AF1火3`。这4G合计`290＋300＋540＋406＝1536`威力，累计ΔP为`1536−4Q≈−570.46`；省去这部分，就对应＋570.46的收益。
