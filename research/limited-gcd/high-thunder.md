# 高闪雷在限定gcd数目1-13下的盈亏

研究日期：2026-10-22。

高闪雷固定在第1个GCD施放，研究这发雷在目标死亡前的期望伤害相对单体基准 `Q=6846/13≈526.6154` 的盈亏。按下述条件，**总共1—7个GCD时为负收益，8—13个GCD时为正收益。**

## 1. 计算条件

- 单目标，100级；目标当前没有雷DoT，高闪雷可用。
- 采用2.45秒复唱配装：咏速787、无黑魔纹，FPS税与操作延迟取0。
- 当前高闪雷在 `t=0` 施放，记为第1个GCD。N为包含打雷这一格的总GCD数，目标在第N个完整GCD窗口结束时死亡，`T=N×2.45秒`。例如N=1时，目标在2.45秒死亡。伤害统计截至目标死亡或消失。
- 天语、团辅和药的加成全程恒定，约去共同倍率，按技能威力计量。
- 雷命中到下一跳的间隔按0—3秒均匀分布，以期望收益判断。

## 2. 威力与期望回本点

| 项目 | 本题采用的数值 |
| --- | ---: |
| 高闪雷 | 直伤150，每跳计入咏速加成为 `60×1.017=61.02`，最多10跳，总计760.20 |
| 单体基准Q | `6846/13 = 526.615384615…` |

雷占1个GCD，成本记为1个Q；总GCD数N用于确定跳伤兑现的时间。设截止前的期望跳数为 `E[k]`，即各种跳伤时机下的平均跳数，可以是小数。

```text
雷的期望威力 = 150 + 61.02×E[k]
相对Q的期望盈亏 ΔP雷 = 150 + 61.02×E[k] − Q
回本期望跳数 = (Q−150)/61.02 ≈ 6.172
施放后回本时间 = 0.757 + 3×回本期望跳数 ≈ 19.273秒
ΔP雷 > 0为正收益，ΔP雷 = 0为打平。
```

## 4. 来源与复算

威力来自[7.2注释版](../../blm/nga-43757414/7.2黑魔进阶攻略-原文注释版.html)，读取时仓库提交为 `8ba3b59498585e4c739373a7c4fa7c92d77dbec0`。时间与跳伤规则采用XIV in the Shell的7.5副本，固定上游提交为 [`08eb81788c343a684fd421a7955a4f0785f61868`](https://github.com/xivintheshell/xivintheshell/tree/08eb81788c343a684fd421a7955a4f0785f61868)；两份资料的高闪雷威力一致。

配装采用[The Balance列出的2.45秒毕业方案](https://www.thebalanceffxiv.com/jobs/casters/black-mage/best-in-slot/#245-high-crit-caster-friendly-bis)，咏速取自其[XivGear配装表](https://xivgear.app/?onlySetIndex=5&page=embed%7Csl%7C08698620-8f30-42df-b4c8-df525fe78a95)，于研究日期查询。

- [BLM.ts](https://github.com/xivintheshell/xivintheshell/blob/08eb81788c343a684fd421a7955a4f0785f61868/src/Game/Jobs/BLM.ts#L962-L973)：高闪雷威力、命中延迟，以及瞬发、0蓝耗、消耗THUNDERHEAD的条件。
- [GameState.ts](https://github.com/xivintheshell/xivintheshell/blob/08eb81788c343a684fd421a7955a4f0785f61868/src/Game/GameState.ts#L315-L333)：公共跳伤节奏，首次事件由 `timeTillFirstManaTick + dotTickOffset` 决定，雷在命中时挂上DoT。
- [XIVMath.ts](https://github.com/xivintheshell/xivintheshell/blob/08eb81788c343a684fd421a7955a4f0785f61868/src/Game/XIVMath.ts#L137-L165)：咏速对DoT威力与GCD的影响；100级DoT倍率为 `(1000 + floor((咏速−420)×130/2780))/1000`。

[high_thunder.py](high_thunder.py)用精确分数计算门槛和期望值，只在输出时舍入；第1个GCD固定打雷，对总共1—13个GCD对应的截止时间各检查3000种跳伤相位，共39,000种情况，并核对上表。

```sh
python3 research/limited-gcd/high_thunder.py --check
```
