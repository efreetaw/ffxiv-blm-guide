# 第一题：当前打高闪雷，后续还有1—13个GCD，收益如何？

研究日期：2026-10-22。

高闪雷固定在当前这个GCD施放，比较它与当前改打其他技能的期望收益。按下述条件，**后续还有1—7个GCD时，当前打火4期望更高；后续还有8—13个GCD时，当前打高闪雷期望更高。**

## 1. 计算条件

- 单目标，100级；目标当前没有雷DoT，高闪雷可用。
- 采用2.45秒复唱配装：咏速787、无黑魔纹，FPS税与操作延迟取0。
- 当前高闪雷在 `t=0` 施放，这一格记为GCD 0。之后还有N个完整GCD窗口，目标在这些窗口结束时死亡，`T=(N+1)×2.45秒`。例如N=1时，后续第1格在2.45秒开始，目标在4.90秒死亡。伤害统计截至目标死亡或消失。
- 双方天语、团辅和药的加成相同且全程恒定，约去共同倍率，按技能威力比较。
- 两个方案只改变当前这一发技能，后续N个GCD的动作相同。
- 雷命中到下一跳的间隔按0—3秒均匀分布，以期望收益判断。

## 2. 威力与期望回本点

| 项目 | 本题采用的数值 |
| --- | ---: |
| 高闪雷 | 直伤150，每跳计入咏速加成为 `60×1.017=61.02`，最多10跳，总计760.20 |
| 火4 / 悖论 | 540 |
| 绝望 | 630 |
| 耀星 | 900 |
| 异言 | 890 |
| 单体基准Q | `6846/13 = 526.615384615…` |

设当前这发雷在截止前的期望跳数为 `E[k]`，当前改打其他技能的威力为C。期望跳数是各种跳伤时机下的平均值，可以是小数。

```text
雷的期望威力 = 150 + 61.02×E[k]
期望收益 E[Δ] = 150 + 61.02×E[k] − C
回本期望跳数 = (C−150)/61.02
E[Δ] > 0为正收益，E[Δ] = 0为打平。
```

| 当前改打的技能 | C | 回本期望跳数（约） | 施放后回本时间（秒，约） |
| --- | ---: | ---: | ---: |
| 原本只能空转 | 0 | 直伤命中即赚 | 0.757 |
| 冰3（按注释版290）/ 冰4 | 290 / 300 | 2.294 / 2.458 | 7.640 / 8.132 |
| AF1火3 | 406 | 4.195 | 13.343 |
| 以Q作平均线比较 | 526.615… | 6.172 | 19.273 |
| AF3火4 / 悖论 | 540 | 6.391 | 19.931 |
| AF3绝望 | 630 | 7.866 | 24.356 |
| 异言 / AF3耀星 | 890 / 900 | 超过10跳上限 | 全程760.20，无法回本 |

表中回本时间为 `0.757 + 3×回本期望跳数`，超过回本点才有正收益。Q是单体基准循环的长期平均威力；具体替换按对应技能的C计算。

## 4. 已有雷或后续循环发生变化时

### 目标身上已经有雷

相同加成下，刷新雷要扣掉覆盖损失：

```text
E[Δ] = 150 + 61.02×（新雷期望跳数 − 因覆盖损失的旧雷期望跳数） − 其他技能的期望损失
```

旧雷损失指新雷命中后、目标消失前，旧雷原本还能跳出的伤害。若旧雷本来就能覆盖到目标消失，刷新只增加150直伤。

### 当前打雷改变后续循环

在同一起始状态、同一截止时间下，两个方案当前分别打雷与替代技能，比较从当前GCD到目标死亡的期望总伤害：

```text
总期望收益 = 打雷方案在截止前的期望总伤害 − 不打雷方案在截止前的期望总伤害
```

例如，插雷使耀星来不及命中，或少打一发火4影响耀星解锁，都要计入后续伤害变化。原本因移动空转的时段能打出雷，则计入额外伤害。

## 5. 来源与复算

威力来自[7.2注释版](../../blm/nga-43757414/7.2黑魔进阶攻略-原文注释版.html)，读取时仓库提交为 `8ba3b59498585e4c739373a7c4fa7c92d77dbec0`。时间与跳伤规则采用XIV in the Shell的7.5副本，固定上游提交为 [`08eb81788c343a684fd421a7955a4f0785f61868`](https://github.com/xivintheshell/xivintheshell/tree/08eb81788c343a684fd421a7955a4f0785f61868)；两份资料的高闪雷威力一致。

配装采用[The Balance列出的2.45秒毕业方案](https://www.thebalanceffxiv.com/jobs/casters/black-mage/best-in-slot/#245-high-crit-caster-friendly-bis)，咏速取自其[XivGear配装表](https://xivgear.app/?onlySetIndex=5&page=embed%7Csl%7C08698620-8f30-42df-b4c8-df525fe78a95)，于研究日期查询。
