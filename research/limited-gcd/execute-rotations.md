# 第三题：核心1—13G的斩杀循环怎么选？

目标在剩余1—13个核心GCD结束时死亡，选择能在截止前命中的收尾结构。前置沿用预存火苗、醒梦可用，不使用魔泉；按整数GCD计算，每发技能必定命中。威力沿用[7.2注释版](../../blm/nga-43757414/7.2黑魔进阶攻略-原文注释版.html)，约去双方相同且恒定的天语、团辅和药倍率。

## 1. 计数与比较口径

本段承接前一火段的绝望、耀星；移位进入UI1后，安排异言填充回蓝，高闪雷为可选位，按第4节的收益判断取舍。填充位置需满足移位回转与表内进火MP要求。

核心不计雷、异言的威力与GCD，表内ΔP只评价核心结构。按注释版的[共同项抵消规则](../../blm/nga-43757414/7.2黑魔进阶攻略-原文注释版.html#section-7)，比较完整方案时，两边相同的雷、异言可以抵消；补雷的差额按第4节另算。

```text
N = 核心GCD数
m = 本段全部异言次数，包含末尾异言
t = 本段高闪雷次数，取0或1
本段总G = N + m + t
从前段绝望开始计整条总G = 本段总G + 2

Q = 6846 / 13
ΔG = N − 13
ΔP = (核心威力 − 6846) − Q × ΔG
   = 核心威力 − N × Q
```

参照为[完整13G／6846威力的标准循环](standard-cycle-cutoff.md#1-循环与算法)。12—13G采用B3→B4的标准回蓝结构。

## 3. 按资源选择5G、6G分支

**5G：**省掉B4后，进火达到2400MP时选`U → 3 → 火4 → D → U`。蓝量不足时选`B4 → U → 核核耀`，威力2508，ΔP＝−125.08；这条通过B4取得回蓝与冰针，进火门槛同样是2400MP。

**6G：**三发异言分别放在首个U前、第二个U后、一档绝望后。承接前段耀星，完整安排为（方括号表示可选）：

```text
星灵 → [高闪雷] → 异言 → U → 星灵 → 3 → D
→ 星灵 → U → 异言 → 星灵 → D₁
→ 异言 → 星灵 → U
```

D₁以AF1的490威力命中，随后升到AF3；再次移位便取得末尾U。异言不足时选`B4 → U → 核核耀 → U`，威力3048，ΔP＝−111.69，进火门槛2400MP。

以上两个备用双核结构省略火3，第一发核爆按AF1的336威力计算，第二发核爆按AF3的432威力计算。

## 4. 高闪雷与截雷的收益判断

沿用[第一题](high-thunder.md#4-已有雷或后续循环发生变化时)的2.45秒配装与跳伤期望口径，在同一起始状态、同一目标死亡时刻下比较：

```text
E[Δ雷] = 150 + 61.02 ×（E[k新] − E[k旧损失]）− C
```

k新为新雷在截止前的有效跳数；k旧损失为新雷覆盖后、截止前旧雷原本还能跳出的次数。C为不打雷方案相对打雷方案多打出的其他技能威力，包含回蓝、移位回转和循环结构变化带来的后续伤害差额。

在满足资源条件的方案中，E[Δ雷]＞0时取t＝1，＜0时取t＝0，＝0时按操作安排选择。若旧雷本来就覆盖到目标死亡，刷新只新增150直伤；若因此挤掉更高威力的技能，则不补雷。例如，新雷跳满10跳、覆盖损失旧雷5跳时，净新增为455.10；若少打一发540威力的火4，收益为−84.90。

跳数按雷命中后的实际剩余时间计算，包括异言占用的时间。核心1—6G与7—13G不是补雷分界：核心6G加3发异言，若雷放在段首，雷后实际还有9G；应按这一时间窗口及旧雷剩余判断。
