# 第三题：不定GCD下的斩杀特化

方案与数值以[第二节HTML选择表](../../docs/不定gcd下的截断特化/index.html#2-2)为准。目标在剩余1—13个核心GCD结束时不可选中，选择能在截止前命中的收尾结构。前置为预存火苗、醒梦与即刻可用，不使用魔泉；按整数GCD计算，每发技能必定命中，约去双方相同且恒定的天语、团辅和药倍率。

## 1. 计数与比较口径

本段承接前一火段的绝望、耀星；移位进入UI1后，安排异言填充回蓝，高闪雷为可选位，按第4节的收益判断取舍。填充位置需满足移位回转与表内进火MP要求。

核心不计雷、异言的威力与GCD，表内ΔP只评价核心结构。按注释版的[共同项抵消规则](../../blm/nga-43757414/7.2黑魔进阶攻略-原文注释版.html#section-7)，比较完整方案时，两边相同的雷、异言可以抵消；补雷的差额按第4节另算。

```text
N = 核心GCD数
m = 本段全部异言次数，包含末尾异言
t = 本段高闪雷次数，取0或1
本段总G = N + m + t
从前段绝望开始计整条总G = 本段总G + 2

Q = 6846 / 13
ΔG = N − 13
ΔP = (核心威力 − 6846) − Q × ΔG
   = 核心威力 − N × Q
```

参照为[完整13G／6846威力的标准循环](standard-cycle-cutoff.md#1-循环与算法)。12—13G采用B3→B4的标准回蓝结构。

### 2.1. 1—5G：无B4

见[1—5G截断特化模型](../../docs/不定gcd下的截断特化/index.html#2-3)。雷与异言填充放在前U之前；3G省略火4，以绝望收尾。2G另有表中的`3 → D`分支。星灵移位之间需满足5秒冷却。

### 2.2. 6—11G：B4体系

见[6—11G截断特化模型](../../docs/不定gcd下的截断特化/index.html#2-4)。雷为可选位，异言填充后再打B4、U；7G核耀分支省略前U。B4取得3根冰针，按表中MP条件选择绝望、双核耀或火4核耀收尾。

### 2.3. 12—13G：B3＋B4

见[12—13G截断特化](../../docs/不定gcd下的截断特化/index.html#2-5)，采用B3→B4回满蓝，完成火4×6、耀星与绝望。

## 3. 相对截断基准的收益

见[收益对比](../../docs/不定gcd下的截断特化/index.html#2-6)。相同核心G数N下，两条方案的N×Q抵消，收益差等于核心威力之差。

例如8G基准前缀为3696威力、ΔP＝−516.92；B4核耀方案为4198威力、ΔP＝−14.92，因此相对截断基准提升`4198−3696＝502`威力。

## 4. 高闪雷与截雷的收益判断

沿用[第一题](high-thunder.md)的2.45秒配装与跳伤期望口径，在同一起始状态、同一目标不可选中时刻下比较：

```text
E[Δ雷] = 150 + 61.02 ×（E[k新] − E[k旧损失]）− C
```

k新为新雷在截止前的有效跳数；k旧损失为新雷覆盖后、截止前旧雷原本还能跳出的次数。C为不打雷方案相对打雷方案多打出的其他技能威力，包含回蓝、移位回转和循环结构变化带来的后续伤害差额。

跳数按雷施放后到截止的时间计算，包含当前雷这一格及异言占用的时间，再扣除0.757秒命中延迟。在满足资源条件的方案中，E[Δ雷]＞0时补雷，＜0时不补，＝0时按操作安排选择。

### 4.1. 总12G：雷替换一发U

对应[截断雷的盈亏](../../docs/不定gcd下的截断特化/index.html#3-3)，两边均安排4发异言：

```text
补雷：  B4 → 雷 → 异言×2 → 3 → 火4×3 → 核 → 耀 → 异言×2
不补雷：B4 → U  → 异言×2 → 3 → 火4×3 → 核 → 耀 → 异言×2
```

补雷为7核心G＋4异言＋1雷；不补雷为8核心G＋4异言。双方进火≥3200MP，第4发异言需通晓回转。补雷少打一发U，因此C＝540。

总时间为`12×2.45＝29.40秒`，新雷在第2G施放，含当前雷还有11格：

```text
新雷时间窗口 = 11×2.45 = 26.95秒
E[k新] = (26.95−0.757)/3 = 8.731
新雷期望威力 = 150＋61.02×8.731 = 682.76562
E[Δ雷] = 682.76562 − 61.02×旧雷损失跳数 − 540
```
