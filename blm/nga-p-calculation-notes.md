## 计算口径

`p` 是比较窗口中的威力盈亏，不是该循环的总威力。记目标窗口为 `S_t、G_t`，参照窗口为 `S_r、G_r`，则：

```text
p = (S_t − Q×G_t) − (S_r − Q×G_r)
  = ΔS − Q×ΔG
```

参照恰好是基准循环时，`S_r − Q×G_r = 0`，才简化为原帖列出的 `p = S_t − Q×G_t`。起手、魔泉和跨循环剩余蓝路线需要先说明共同项；把这些结构当成一段普通循环直接相加，会混入参照本身的收益。

复算使用下列元素修正后的威力。共同的天语倍率不额外乘入，因此数值与原帖的 p 单位一致。A/U 分别表示火/冰悖论，F4 是炽炎，B4 是冰针，D 是绝望，核是核爆，耀是耀星。

| 技能与施放前状态 | 本稿计入的威力 |
| --- | ---: |
| A、U | 540；悖论不增加冰火档数 |
| F4，三档火 | 300×1.8＝540 |
| D，三档火 | 350×1.8＝630 |
| 核，一档火 / 三档火 | 240×1.4＝336 / 240×1.8＝432 |
| 耀，三档火 | 500×1.8＝900 |
| B4，在冰状态 | 300 |
| B3，一档冰 / 一档火 / 三档火 | 290 / 290×0.9＝261 / 290×0.7＝203 |
| F3，一档火 / 一档冰 / 三档冰 | 290×1.4＝406 / 290×0.9＝261 / 290×0.7＝203 |

星灵移位、魔泉、醒梦、即刻、三连、黑魔纹、详述等能力技不占 GCD，不计伤害。雷、异言和秽浊本身有伤害并占 GCD；只有在比较双方使用相同填充资源、相同有效雷伤时，才能从双方同时消去。下面的“核心序列”采用这个共同项抵消口径，不能把它理解成这些技能没有威力或不占 GCD。

循环图经常画出上一段的绝望/耀星作为连接。每条注释都要统一窗口边界，不能同时把上一段结尾和本段结尾各算一次；跨段收益另行标明。

### 单体基准与精度

基准核心是 `B3[冰1] → B4 → U → F3[火1] → F4×6 → A → 耀 → D`，共 13 GCD：

```text
S_base = 290 + 300 + 540 + 406 + 6×540 + 540 + 900 + 630 = 6846
Q = 6846÷13 = 526.615384615…
```

原帖把 Q 显示为 526.6。本稿先保留完整精度，最后舍入；同时指出用已舍入中间数计算会造成的差异。不能为了凑原帖末位而调整技能威力。

### 魔泉与起手参照

常规魔泉的额外火段 `F4×6 + A + 耀 + D` 共 9 GCD、5310 威力。为了比较魔泉用法，下面以“一段基准循环＋这段常规魔泉”为参照：`S_r＝12156，G_r＝22`。这是复算所用的参照账本；原帖没有逐条展开此账本。

起手另用常规 `4F4+D → M → 6F4+A+耀+D` 的核心为参照，`S_r＝8100，G_r＝14`。双方相同的起手 F3、雷和填充先抵消。这个参照没有被设为一段普通 13 GCD 基准，所以起手注释使用 `ΔS−Q×ΔG`。

## AOE

多目标相加时，核爆对次目标按 70% 计，耀星按 35% 计。记目标数 n：

```text
核[火1] = 336×[1+0.7(n−1)]
核[火3] = 432×[1+0.7(n−1)]
耀       = 900×[1+0.35(n−1)]
玄冰     = 120n
```

B4 和悖论是单目标威力，不能乘 n。下列“跳过 U”的 p 同样抵消双方共同的雷/秽浊填充，不能额外再加一整记填充的伤害。
