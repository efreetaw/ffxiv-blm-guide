# NGA 43757414 图片与 p 值复核

## 结论

- 正文镜像共提取 **40 张内容图**：4 张章节封面，36 张循环/公式图。
- 正文出现 **28 个 p 结论**。
- 其中 **12 个可直接独立复算**，**10 个能由相邻循环的技能差值交叉验证**，**2 个是作者定义的多目标基准**。
- **4 个绝对值无法只靠公开图片独立闭合**：截断起手、冰针5+7、一档核爆魔泉双耀星、剩余蓝3+核+0。缺的是作者没有写在正文里的对照边界、跳蓝和资源机会成本。
- 没发现明确的大额算错。`剩余蓝冰针6+0改 p=16.4` 有约 **0.1** 的舍入疑点；`剩余蓝A即刻冰3 p=-132` 是整数近似，按精确值约为 **-132.4**。

## 统一计算口径

星灵移位、即刻咏唱、三连咏唱、魔泉、醒梦均为能力技，按 **0 GCD、0 威力** 处理。

基准循环的 13 个伤害 GCD 为：

`冰3(290) + 冰4(300) + 冰悖论(540) + 火悖论(540) + AF1火3(406) + 火4×6(3240) + 耀星(900) + 绝望(630)`

总威力：

`290 + 300 + 540 + 540 + 406 + 3240 + 900 + 630 = 6846`

精确基准 PPG：

`6846 / 13 = 526.615384615...`

界面显示成 `526.62` 没问题；实际累计计算最好保留 `6846 / 13`，避免长轴因提前四舍五入产生漂移。

单体常用威力均不计天语，但保留冰火状态倍率：

| 技能/状态 | 威力 |
|---|---:|
| 火4（AF3） | 540 |
| 耀星（AF3） | 900 |
| 绝望（AF3） | 630 |
| 悖论 | 540 |
| 核爆（AF1 / AF3） | 336 / 432 |
| 火3（UI3 / UI1 / 无状态 / AF1） | 203 / 261 / 290 / 406 |
| 冰3、冰4 | 290、300 |

## 关键公式

### 5+7

相对标改的变化为：多一个耀星；绝望降级为火4；魔泉里的火悖论替换成等威力的火4。

`(900 - 526.6153846) + (540 - 630) + (540 - 540) = 283.3846154 → 283.4`

### 核爆起手

`(900 - 526.6153846) + (432 - 630) = 175.3846154 → 175.4`

### U3d

`540 + 406 + 630 - 3 × 526.6153846 = -3.8461538 → -3.8`

### UM / AM

魔泉是能力技，不占 GCD；核心只多一发威力 540 的悖论：

`540 - 526.6153846 = 13.3846154 → 13.4`

### B4A 核核耀

第一发核爆处于 AF1，威力 `240×1.4=336`；第二发处于 AF3，威力 `240×1.8=432`。

`300 + 540 + 336 + 432 + 900 - 5 × 526.6153846 = -125.0769231 → -125.1`

### 多目标跳过冰悖论

- 双目标：`672 - 540 = 132`
- 三目标：`854.6 - 540 = 314.6`

图里的秽浊属于填充技能，不属于“B4/玄冰 + 核核耀”改动包本身；因此不能把整张图所有图标直接相加后套单体 `526.62`。
