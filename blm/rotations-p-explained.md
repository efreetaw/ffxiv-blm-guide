## 一 底层逻辑

黑魔特化的比较先要确定同一资源条件下的对照。多打一发高威力技能，并不等于多赚了它的全部威力；它占用的 GCD 也要付出基准威力。替换同一个 GCD 内的技能时，则只比较威力差。本文用 p 表示这种相对盈损，正数为相对收益，负数为相对损失。

### 统一规则

记单体基准 `Q = 6846 / 13 = 526.615384615…`。完整且资源边界一致的序列可算 `p = 总威力 − 伤害GCD数 × Q`；比较改动则用 `Δp = Δ威力 − ΔGCD × Q`。

星灵移位、即刻咏唱、三连咏唱、魔泉、醒梦均按 `0 GCD、0 威力` 处理。它们造成的冰火状态、MP、火苗和星极魂变化仍必须反映在资源账中，不能因为能力技不占 GCD 就忽略其后续影响。

| 改动 | 计算 | 精确收益或损失 |
|---|---|---:|
| 额外一个火4或悖论 | `540 − Q` | `13.384615385…` |
| 额外一个绝望 | `630 − Q` | `103.384615385…` |
| 额外一个耀星 | `900 − Q` | `373.384615385…` |
| 同 GCD 把绝望换成火4 | `540 − 630` | `−90` |
| 同 GCD 把 AF1 火3换成 UI1 火3 | `261 − 406` | `−145` |

常用技能威力如下。AF 指星极火，UI 指灵极冰，数字为状态档数；以下不计天语，已保留冰火状态倍率。

| 技能和状态 | 威力 |
|---|---:|
| 火4 AF3 | 540 |
| 耀星 AF3 | 900 |
| 绝望 AF3 | 630 |
| 悖论 | 540 |
| 核爆 AF1 / AF3 | 336 / 432 |
| 火3 UI3 / UI1 / 无状态 / AF1 | 203 / 261 / 290 / 406 |
| 冰3 / 冰4 | 290 / 300 |

多目标计算使用对应目标数的基准，不使用单体 `Q`。p 的最终显示可以四舍五入，累计计算应保留未舍入数；相邻序列已显示到一位小数的 p 不能直接当作精确底数。
